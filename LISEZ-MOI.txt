APPLICATION BOFO UNHCR RESTAURANT — NETLIFY CAMEROUN

Déposez le dossier complet dans un dépôt GitHub connecté à Netlify. Les fichiers
netlify.toml et netlify/functions/menu.mjs permettent à Netlify de récupérer le
menu Google Sheets sans que le téléphone se connecte directement à Google.

Contenu à déposer à la racine du dépôt :
- index.html
- manifest.json
- sw.js
- config.js
- menu.csv
- menu.txt
- icon.svg
- icon-192.png
- icon-512.png
- netlify.toml
- dossier netlify/functions

Dans GitHub : Settings > Pages > Deploy from a branch > main > /(root) > Save.

Le formulaire comprend le menu, le calcul du total, la livraison aux bureaux de l’UNHCR à Bastos, l’étage et le bureau. Le numéro de Pama est facultatif. La commande est préparée pour WhatsApp au +237 658 727 116.

MISE À JOUR AUTOMATIQUE DEPUIS GOOGLE SHEETS AU CAMEROUN
1. Importez BOFO_Menu_Quotidien.xlsx dans Google Sheets.
2. Dans Google Sheets : Fichier > Partager > Publier sur le Web.
3. Choisissez seulement l’onglet Menu, puis le format « Valeurs séparées par des virgules (.csv) ».
4. Copiez le lien fourni par Google.
5. Le fichier .github/workflows/actualiser-menu.yml récupère automatiquement le tableau toutes les 15 minutes.
6. Dans GitHub, ouvrez Actions > Actualiser le menu BOFO > Run workflow pour lancer la première actualisation immédiatement.
7. Netlify republiera ensuite automatiquement menu.csv et menu.txt. L'application charge menu.txt depuis Netlify et ne contacte plus Google Sheets.

CATEGORIES DU TABLEAU
Dans la colonne Categorie, utilisez Plats, Accompagnements ou Boissons. Les articles
seront automatiquement rangés dans les trois sections correspondantes de l'application.

Installation Android : ouvrir le lien dans Chrome puis choisir « Installer l’application ».
Installation iPhone : ouvrir le lien dans Safari, toucher Partager puis « Sur l’écran d’accueil ».
