APPLICATION BOFO UNHCR RESTAURANT — GITHUB PAGES

Contenu à déposer à la racine du dépôt GitHub :
- index.html
- manifest.json
- sw.js
- icon.svg

Dans GitHub : Settings > Pages > Deploy from a branch > main > /(root) > Save.

Le formulaire comprend le menu, le calcul du total, la livraison aux bureaux de l’UNHCR à Bastos, l’étage et le bureau. Le numéro de Pama est facultatif. La commande est préparée pour WhatsApp au +33 6 87 08 17 24.

Installation Android : ouvrir le lien dans Chrome puis choisir « Installer l’application ».
Installation iPhone : ouvrir le lien dans Safari, toucher Partager puis « Sur l’écran d’accueil ».
